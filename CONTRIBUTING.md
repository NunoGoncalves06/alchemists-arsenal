# Contributing

Thanks for wanting to help with Alchemist's Arsenal.

## Reporting a bug

Open an issue with the **Bug report** template. Say what you did, what you expected and what happened instead. A screenshot helps a lot, and so does the log file from:

```
%USERPROFILE%\AppData\LocalLow\Alchemists Arsenal Team\AlchemistsArsenal\Player.log
```

Include the game version (it's on the [Releases](../../releases) page you downloaded from).

## Suggesting something

Open an issue with the **Feature request** template. Ideas for balance, new monsters or anything that felt off while playing are all welcome.

## Pull requests

The project is not open source (see [LICENSE](LICENSE)), so pull requests are only accepted when they were agreed on in an issue first. If you'd like to work on something, open an issue and ask.

When a pull request has been agreed on:

- Branch from `dev` and open the pull request against `dev`.
- Keep it to one change, with a commit message that says what it does.
- Open the project in Unity 6000.6 and make sure it compiles and the game still starts.
