The game now runs on Linux as well as Windows.

**What's new**

- A Linux x64 build, `AlchemistsArsenal-Linux.tar.gz`.
- The game ships its own fonts (Gelasio, Selawik and Inconsolata, all under the SIL Open Font License), so the text looks the same on every system instead of depending on the fonts your PC happens to have.

**Download**

- Windows: `AlchemistsArsenal-Windows.zip`. Unzip it, keep the files together, and run `AlchemistsArsenal.exe`. Windows may warn that it protected your PC because the game isn't signed: click **More info**, then **Run anyway**.
- Linux: `AlchemistsArsenal-Linux.tar.gz`. Unpack it with `tar -xzf` and run `./AlchemistsArsenal/AlchemistsArsenal.x86_64`.

Needs Windows 10 or 11 (64-bit) with a DirectX 11 graphics card, or Linux x86_64 with Vulkan or OpenGL 4.5.
