# Security policy

## Supported versions

Only the latest release on the [Releases](../../releases) page gets fixes.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Use GitHub's private reporting instead: go to the **Security** tab of this repository and click **Report a vulnerability**. Only the maintainer can see the report.

You'll get an answer as soon as possible. If the problem is confirmed, it will be fixed in the next release and you'll be credited in the release notes, unless you'd rather not be.
